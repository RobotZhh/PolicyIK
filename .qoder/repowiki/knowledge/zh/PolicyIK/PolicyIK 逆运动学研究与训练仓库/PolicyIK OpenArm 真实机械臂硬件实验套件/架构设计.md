本模块以 `hardware/config.yaml` 为单一配置源，由 `policyik_hw/` 下的 Python 包按职责分层协作：
- `robot/` 提供底层 ROS 2 I/O、电机健康监控与安全预检查，被 `envs/pose_env.py` 在每步控制前调用以实现碰撞/限位保护。
- `envs/` 暴露 gymnasium 环境，封装关节观测、密集奖励 (`reward.py`) 与逆起点课程采样 (`workspace.py`)，供 RL 算法消费。
- `rl/` 实现基于 TorchUniformBuffer 的 HER 回放缓冲与在线学习钩子 (`learner_hooks.py`)，由 `cli_scripts/train.py` 在控制周期内触发梯度更新。
- `utils/kinematics.py` 与 `utils/pose_math.py` 为环境与 robot 共享的正/逆运动学与位姿数学原语。
- 顶层 `train.py / evaluate.py / collect_demos.py / select_tasks.py / watchdog_check.py / metrics.py` 作为 Python CLI 入口，分别对应 shell 脚本 `scripts/*.sh`。
- `data/` 提供 `demos.npz`、任务定义与元数据，被 `rl/demos.py` 与 `select_tasks.py` 读取；`config.yaml` 中 `demos.task_pool` 指向 `data/task_pool.json`，形成数据契约。
- `install.sh` 固定克隆 openarm_can/ros2/description 三个 ROS 2 仓库到 `<repo>/src/`，通过 colcon 构建并创建带 `--system-site-packages` 的 `.venv`，使 Python 侧能同时访问 ROS 2 包与 PolicyIK 包。
