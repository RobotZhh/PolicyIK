模块由三类文件组成：
- `hardware/config.yaml`：集中描述环境参数（关节限位、碰撞包络、控制频率）、奖励函数、课程学习、Agent/HER 超参、演示数据路径与日志目录，所有相对路径以该文件所在目录为根解析。
- `hardware/scripts/*.sh`：薄包装器，`cd` 到 `hardware/` 后通过 `python3 -m policyik_hw.*` 调用 Python 入口（`train` / `collect_demos` / `evaluate` / `watchdog_check` / `robot.park`），不承载业务逻辑；`train_watchdog.sh` 独立守护进程，轮询 `<run_dir>/buffer_step*` 新检查点并调用 `policyik_hw.watchdog_check`，异常时发送 SIGINT 终止 trainer 并执行 `park` 回零。
- `hardware/install.sh`：一次性初始化脚本，固定三个 openarm 仓库的 git commit，`source /opt/ros/jazzy/setup.bash` 后 `rosdep install` + `colcon build --packages-up-to openarm_right_bringup`，再创建带 `--system-site-packages` 的 `.venv` 并安装 `requirements/hardware.txt`。
依赖方向单向：shell → Python 模块 `policyik_hw` → ROS2/openarm 硬件层；config.yaml 是 shell 与 Python 共享的唯一配置源。
