- 所有可配置项以 `dataclass` 形式集中声明（如 `FlashSACConfig`），并通过 `replace(cfg, ...)` 在构造时派生衍生字段（如 `temp_target_entropy`、`compile_mode`）。
- Agent 与 Buffer 均通过 ABC 抽象基类（`BaseAgent`、`BaseBuffer`）定义统一接口，子类只实现具体策略与存储细节。
- 神经网络统一由 `agents.utils.network.Network` 包装，对外暴露 `apply(method, ...)` 调用底层方法，并提供 `save/load` 序列化包含 network_state_dict、optimizer_state_dict、scheduler_state_dict 与 update_step。
- 设备与 dtype 转换集中在入口层：`TorchUniformBuffer.__init__` 与 `FlashSACAgent.__init__` 中统一将字符串 device 规范化为 `cuda:X` 或 `cpu`，并将 numpy 数据经 `_to_tensor` 或 `torch.as_tensor(..., dtype=torch.float32)` 转至目标设备。
- checkpoint 路径通过 `os.makedirs(path, exist_ok=True)` 自动创建目录，并以分文件命名（actor.pt、critic.pt、target_critic.pt、temperature.pt、replay_buffer.pt、agent_state.pt）组织。
- 对性能敏感的小函数（如 `_build_truncated_zeta_cdf`、`_sample_integer_from_cdf`）使用 `@torch.compile` 装饰，而 Network 包装器在 `compile_network=True` 时对 `normalize_parameters` 与 EMA 更新函数也进行编译。
