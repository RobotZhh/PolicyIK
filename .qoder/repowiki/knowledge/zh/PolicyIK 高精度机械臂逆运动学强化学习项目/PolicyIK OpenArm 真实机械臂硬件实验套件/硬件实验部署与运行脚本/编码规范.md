- Shell 脚本统一以 `set -eu`（或 `set -u`）开头并通过 `cd "$(dirname "$0")/.."` 切换到 `hardware/` 目录后再 `exec python3 -m policyik_hw.*` 调用 Python 入口。
- 所有可复现实验的参数集中在 `config.yaml` 中，shell 脚本仅透传 `--config config.yaml`，不在脚本内硬编码数值。
- 长时运行的训练/评估支持中断续跑：通过 `--init-from` / `--init-buffer` / `--step-offset` 以及已存在的 `summary.json` 中的 `global_steps_completed` 字段恢复。
- 看门狗通过监听 `<run_dir>/buffer_step*` 文件增量来触发检查，并使用 `pgrep -f "^python3 -m policyik_hw\.train .*--name $NAME"` 定位同名 trainer 进程。
