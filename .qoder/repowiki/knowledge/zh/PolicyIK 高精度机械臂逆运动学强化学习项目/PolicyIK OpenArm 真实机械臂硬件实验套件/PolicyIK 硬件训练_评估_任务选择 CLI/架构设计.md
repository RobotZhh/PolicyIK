三个并列的 `main()` 入口脚本，均通过 `argparse` 暴露 CLI 参数并依赖同包内的环境、RL 与机器人抽象：
- `train.py`：加载 YAML 配置 → 解析 `--checkpoint-at` / `--init-from` / `--step-offset` 等恢复选项 → 构建 `OpenArmPoseEnv` + `FlashSACAgent` + `PoseHERRLPDBuffer`（含 HER 重标记与演示回放）→ 带 SIGINT 双次确认的步循环 → 输出 `metrics.jsonl` / `episodes.jsonl` / `summary.json`。
- `evaluate.py`：读取训练产出的 `config.json`，复用 `train.build_agent(training=False)` 加载检查点，按 `task-file` 中的 `{q_start, goal_p, goal_R}` 逐条执行确定性 episode，结果以 `.tmp` + `os.replace` 原子写入 JSON。
- `select_tasks.py`：离线从 `PoseCloud` 中按旋转角度 band × 径向 shell 分层抽样，用 `make_rollout` 在动作律下做无噪声前向仿真并通过关节限位 / 包络 / 工作区校验，输出 `demo_tasks.json`。
依赖方向单向向外：本模块仅 import `.envs.*`、`.rl.*`、`.utils.kinematics`、`.robot.*`，不反向被这些子包引用；ROS 初始化 (`rclpy.init/shutdown`) 仅在 `io is None` 时触发，便于被外部进程注入 IO。
