本模块由三个彼此独立的 Python 脚本组成，均通过 `if __name__ == "__main__"` 暴露命令行入口，不互相 import：
- `collect_demos.py`：基于 `.envs.pose_env.OpenArmPoseEnv` 驱动真实机械臂执行大旋转轨迹，按任务文件顺序生成 `.npz` 演示数据；支持断点续跑（读取已有 ep_id/ep_t 并丢弃不完整 episode）、dry-run、以及通过 `rclpy` 初始化 ROS 控制栈。
- `watchdog_check.py`：从训练运行目录加载 `buffer_step{step}` 或 `bufferfinal` 的 torch buffer，检查最近 WINDOW=5000 步中关节角速度接近零但指令偏差超阈值的“卡住”模式，并结合 `episodes.jsonl` 判断最近距离是否退化，以退出码区分正常/异常。
- `metrics.py`：聚合同一 checkpoint 下三个 gap-bin (`medium`/`long`/`extended`) 的 `eval_*.json` 结果，按预算窗口 (15s,25s) 统计 held/reached 计数与末位误差，输出汇总 JSON 与表格。
依赖方向单向指向上层包 `.envs`、`.rl.demos`、`.robot.ros_io`、`.utils.kinematics`，本模块自身不包含任何可被其他代码复用的 API。
