三个并列的独立脚本，均通过 `isaaclab.app.AppLauncher` 启动 Isaac Sim，再借助 `hydra_task_config` 从 `policyik_sim.tasks` 加载环境配置与 `rl_games_cfg_entry_point` 对应的 RL-Games 配置。
- `train.py`：解析 CLI → 构造 `ManagerBasedRLEnvCfg` / `DirectMARLEnvCfg` → `gym.make(task)` → 可选 `RecordVideo` → `RlGamesVecEnvWrapper` + `RlGamesGpuEnv` 注册到 rl-games 的 `env_configurations` → `Runner(IsaacAlgoObserver | MultiObserver)` 执行训练，支持多 GPU (`distributed`)、W&B 跟踪、PBT、checkpoint 续训与 IO descriptors 导出。
- `evaluate.py`：固定 `rl_games_cfg_entry_point`，加载 `.npz` 任务文件（`q_start, goal_pos, goal_quat`），以批量方式在 `num_envs` 个环境中运行策略，支持可选的瞬态目标（偏移 + 旋转）并输出每步位姿误差与末端位姿轨迹。
- `metrics.py`：纯 NumPy 后处理，读取 evaluate 输出的 `single.npz` / `corrected.npz` / `transient{k}.npz`，按严格/粗粒度阈值计算单尝试成功率、进入时间、漂移，以及“单尝试→误差修正→8次瞬态”部署协议的累计成功曲线与 E[N]。
依赖方向单向：`train.py` 和 `evaluate.py` 产出数据，`metrics.py` 消费数据；三者都依赖 `isaaclab_tasks` 与 `policyik_sim.tasks` 完成 Hydra 配置解析。
