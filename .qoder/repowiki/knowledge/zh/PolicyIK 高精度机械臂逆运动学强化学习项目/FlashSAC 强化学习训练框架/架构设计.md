模块按职责划分为三个子包：
- `agents/`：定义 `BaseAgent[Config]`（`base_agent.py`）抽象接口，当前唯一具体实现是 `flashSAC/agent.py` 中的 `FlashSACAgent`，其内部通过 `_init_flashsac_networks` 组装 Actor、Critic、Target Critic、Temperature 四个 `Network` 包装器，并调用 `update_actor/critic/target_temperature` 等函数完成 SAC 更新。
- `buffers/`：定义 `BaseBuffer` 抽象接口，`torch_buffer.py` 提供 `TorchUniformBuffer` 环形缓冲区，支持 n-step 返回累积与 GPU pin_memory 优化。
- `agents/utils/`：通用基础设施，`network.py` 的 `Network` 类统一封装 nn.Module + optimizer + scheduler + torch.compile + EMA + weight normalization；`reward_normalization.py`、`scheduler.py`、`distribution.py` 提供辅助能力。
依赖方向单向：`agents.flashSAC` → `agents.utils` → `buffers` → `types`；`types.py` 仅暴露 `NDArray` / `F32NDArray` / `Tensor` 类型别名供全模块共享。所有可持久化对象（Network、Buffer、Agent）均提供对称的 `save/load` 接口，checkpoint 以 `.pt` 文件形式分文件存储。
